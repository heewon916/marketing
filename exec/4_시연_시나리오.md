# 시연 시나리오

## 문서 개요

이 문서는 로그인과 기본 연동이 완료된 사용자를 기준으로, 서비스의 핵심 기능을 실제 발표 순서대로 시연하기 위한 운영 스크립트다.
시연 흐름은 홈 진입부터 게시물 생성, 인스타그램 발행 확인, 마이페이지 통계 확인까지 이어진다.

### 시연 목적

- 점주가 간단한 대화와 영상 촬영만으로 게시물을 생성하고 발행할 수 있음을 보여준다.
- AI 가이드, 이미지 후보 선택, 캡션 수정, 인스타그램 발행, 주간 통계 반영까지 하나의 흐름으로 설명한다.

### 시연 시작 조건

- 시연자는 이미 로그인된 상태다.
- 인스타그램 연동이 완료된 계정이다.
- 시연용 샘플 영상 촬영이 가능한 기기 상태다.
- 게시 가능한 인스타그램 계정 상태다.
- 마이페이지 통계 데이터가 조회 가능한 상태다.

## 1. 전체 시연 흐름 요약

| 단계 | 화면명 | 사용자 행동 | 핵심 결과 |
| --- | --- | --- | --- |
| 1 | 홈 진입 | 홈 화면으로 들어간다 | 알림성 문구와 TTS가 노출된다 |
| 2 | 홈 화면 | 입력창 또는 마이크로 게시 의도를 말한다 | 게시물 생성 흐름으로 진입한다 |
| 3 | 게시 의사 확인 | `예`를 누른다 | 게시 생성 단계가 시작된다 |
| 4 | 촬영 가이드 확인 | 가이드 문구를 확인하고 `예`를 누른다 | 카메라 촬영 단계로 이동한다 |
| 5 | 카메라 촬영 | 영상을 촬영한다 | 영상 업로드 및 프레임 추출이 진행된다 |
| 6 | 사진 후보 확인 | 후보 사진을 넘겨보고 선택한다 | 게시물 초안 생성 단계로 넘어간다 |
| 7 | 생성 게시물 확인 | 생성된 카드뉴스와 캡션을 확인한다 | 수정 또는 발행을 선택할 수 있다 |
| 8 | 캡션 수정 | 문구를 수정하고 미리보기 또는 발행을 누른다 | 최종 게시 문구가 반영된다 |
| 9 | 발행 결과 | 발행 완료 화면을 확인한다 | 인스타그램 이동 또는 홈 복귀가 가능하다 |
| 10 | 인스타 확인 | 인스타그램 보기 버튼으로 실제 게시물을 확인한다 | 실제 발행 결과를 보여준다 |
| 11 | 마이페이지 통계 | `내 정보` → `통계`로 이동한다 | 주간 달성률, 노출수, 방문 관심도를 보여준다 |

## 2. 단계별 상세 시연

### 1단계. 홈 진입

**화면명**

- 홈 화면

**라우트 또는 화면 위치**

- `/home`

**사전 상태**

- 로그인 완료
- 푸시 알림 또는 홈 진입 후 바로 시연 시작

**시연자 행동**

- 홈 화면에 진입한다.
- 상단 문구와 캐릭터 영역을 먼저 보여준다.

**클릭 위치**

- 별도 클릭 없음

**화면 반응**

- 상단에 안내 문구가 표시된다.
- 캐릭터가 중앙에 노출된다.
- TTS 또는 준비된 음성이 재생된다.

**설명 멘트**

- “사용자가 앱에 들어오면 먼저 오늘 올릴 이야기가 있는지 자연스럽게 말을 걸어줍니다.”
- “푸시 알림 전용 화면은 없고, 실제 시연에서는 홈 진입 후 이 안내 문구가 알림 진입 장면을 대신합니다.”

**실패 시 대체 진행**

- TTS가 재생되지 않으면 상단 문구만 보여주고 다음 단계로 진행한다.

### 2단계. 홈 화면에서 게시 의도 입력

**화면명**

- 홈 화면 입력 단계

**라우트 또는 화면 위치**

- `/home`

**사전 상태**

- 홈 화면 진입 완료

**시연자 행동**

- 점주 역할로 게시하고 싶은 내용을 말한다.
- 추천 시연 문구 예시:
  - “오늘 같은 날 커피 홍보글 올리고 싶어.”

**클릭 위치**

- 텍스트 입력 시: 하단 중앙 입력창
- 음성 입력 시: 입력창 왼쪽 원형 마이크 버튼
- 전송 시: 입력창 오른쪽 화살표 버튼

**화면 반응**

- 입력된 발화가 서버로 전송된다.
- 일반 대화가 아니라 게시 의도라고 판단되면 게시물 생성 플로우로 이동한다.

**설명 멘트**

- “점주는 복잡한 메뉴를 고르지 않고, 그냥 말하듯이 오늘 홍보하고 싶은 내용을 입력하면 됩니다.”
- “텍스트 입력과 음성 입력 둘 다 가능한 구조입니다.”

**실패 시 대체 진행**

- 음성 인식이 불안정하면 바로 텍스트 입력으로 전환한다.
- 대화 응답만 오고 생성 흐름으로 안 넘어가면, 게시 의도가 더 분명한 문장으로 다시 입력한다.

### 3단계. 게시 의사 확인

**화면명**

- 게시 의사 확인 화면

**라우트 또는 화면 위치**

- `/post-create`
- `QuestionStep`

**사전 상태**

- 홈 화면 입력 완료

**시연자 행동**

- 화면의 질문을 확인한 뒤 게시 생성에 동의한다.

**클릭 위치**

- 하단 오른쪽 기본 버튼 `예`

**화면 반응**

- 1단계 진행바가 보인다.
- 다음 로딩 단계로 이동한다.

**설명 멘트**

- “사용자의 의도를 파악한 뒤, 정말 게시물 생성으로 이어갈지 한 번 더 확인합니다.”

**실패 시 대체 진행**

- 잘못 눌렀을 경우 하단 왼쪽 `아니오`로 홈으로 돌아갈 수 있다고 설명만 하고, 실제 시연은 `예`로 진행한다.

### 4단계. 촬영 가이드 확인

**화면명**

- 촬영 가이드 확인 화면

**라우트 또는 화면 위치**

- `/post-create`
- `QuestionStep`

**사전 상태**

- 게시 의사 확인 완료

**시연자 행동**

- AI가 제안한 촬영 가이드 문구를 읽고 동의한다.

**클릭 위치**

- 하단 오른쪽 기본 버튼 `예`

**화면 반응**

- 가이드 문구가 상단 제목 영역에 표시된다.
- 다음 단계에서 카메라 촬영 화면으로 이동한다.

**설명 멘트**

- “단순히 글만 만드는 게 아니라, 지금 상황에 맞게 어떤 구도로 찍으면 좋을지 먼저 가이드를 줍니다.”

**실패 시 대체 진행**

- 가이드 문구가 기대보다 길거나 다르게 나오면, “이 단계에서 촬영 방향을 제안해 준다”는 기능 포인트만 설명하고 다음으로 진행한다.

### 5단계. 카메라 촬영

**화면명**

- 카메라 촬영 화면

**라우트 또는 화면 위치**

- `/post-create`
- `CameraStep`

**사전 상태**

- 촬영 가이드 확인 완료

**시연자 행동**

- 카메라 미리보기를 보여준다.
- 필요 시 렌즈를 전환한다.
- 약 5초 내외로 짧게 촬영한다.

**클릭 위치**

- 하단 중앙 큰 원형 녹화 버튼
- 필요 시 중간 하단 `렌즈 전환`
- 종료 시 상단 우측 닫기 아이콘

**화면 반응**

- 녹화가 시작되면 남은 시간이 숫자로 보인다.
- 녹화가 끝나면 업로드와 추출 로딩으로 넘어간다.

**설명 멘트**

- “점주는 사진을 여러 장 직접 고르지 않아도 되고, 짧은 영상만 찍으면 됩니다.”
- “가이드를 받은 뒤 그대로 촬영하면 이후 프레임 추출과 보정이 자동으로 이어집니다.”

**실패 시 대체 진행**

- 카메라 권한 문제가 있으면 미리 권한을 허용한 상태라고 설명하고 재시도한다.
- 실시간 촬영이 어렵다면 사전 준비한 동일 흐름의 시연 영상으로 대체한다.

### 6단계. 사진 추출 및 후보 확인

**화면명**

- 사진 추출 로딩
- 사진 후보 확인 화면

**라우트 또는 화면 위치**

- `/post-create`
- `ExtractLoadingStep` 이후 `PhotoConfirmStep`

**사전 상태**

- 촬영 완료

**시연자 행동**

- 잠시 로딩을 보여준 뒤, 추출된 사진 후보를 좌우로 넘겨본다.
- 마음에 들지 않는 사진이 있으면 삭제한다.
- 선택이 끝나면 다음 단계로 이동한다.

**클릭 위치**

- 중앙 캐러셀 영역 좌우 스와이프
- 캐러셀 하단 삭제 버튼
- 하단 오른쪽 기본 버튼 `글 확인`

**화면 반응**

- 영상에서 추출된 후보 사진이 캐러셀로 표시된다.
- 삭제 시 해당 사진이 목록에서 제외된다.
- `글 확인` 클릭 시 게시물 초안 생성으로 이동한다.

**설명 멘트**

- “영상에서 자동으로 프레임을 뽑아준 뒤, 점주는 결과만 보고 고르면 됩니다.”
- “완전 자동이 아니라 사용자가 후보를 한 번 확인하고 정제할 수 있게 했습니다.”

**실패 시 대체 진행**

- 사진이 마음에 안 들면 삭제 기능만 짧게 보여주고 바로 `글 확인`으로 진행한다.
- 추출 실패 시, 재촬영이 가능하다는 점만 설명하고 준비된 성공 케이스로 넘어간다.

### 7단계. 생성 게시물 확인

**화면명**

- 생성 게시물 확인 화면

**라우트 또는 화면 위치**

- `/post-create`
- `GeneratedPostStep`

**사전 상태**

- 사진 후보 선택 완료

**시연자 행동**

- 생성된 이미지와 캡션 초안을 보여준다.
- 먼저 결과물을 훑어본 뒤 수정 단계로 이동한다.

**클릭 위치**

- 하단 왼쪽 버튼 `수정하기`
- 바로 발행 시 하단 오른쪽 버튼 `발행하기`

**화면 반응**

- 생성된 게시물 미리보기가 화면에 표시된다.
- `수정하기`를 누르면 편집 화면으로 이동한다.

**설명 멘트**

- “이 단계에서 AI가 만든 초안 게시물을 바로 확인할 수 있습니다.”
- “사용자는 자동 생성 결과를 그대로 써도 되고, 바로 수정할 수도 있습니다.”

**실패 시 대체 진행**

- 결과물이 기대와 다르면 “초안은 바로 수정 가능하다”는 점을 강조하고 편집 단계로 자연스럽게 넘긴다.

### 8단계. 캡션 수정

**화면명**

- 생성 게시물 편집 화면

**라우트 또는 화면 위치**

- `/post-create`
- `GeneratedPostEditStep`

**사전 상태**

- 생성 게시물 확인 완료

**시연자 행동**

- 캡션 본문을 한두 문장 정도 가볍게 수정한다.
- 수정 후 미리보기로 돌아가거나 바로 발행한다.

**클릭 위치**

- 본문 입력 영역
- 하단 왼쪽 버튼 `미리보기`
- 하단 오른쪽 버튼 `발행하기`

**화면 반응**

- 본문이 수정된다.
- 미리보기 선택 시 최종 미리보기로 돌아간다.
- 발행 선택 시 실제 발행 프로세스가 시작된다.

**설명 멘트**

- “자동 생성이 핵심이지만, 최종 문구에 대한 통제권은 점주가 가지고 있습니다.”
- “필요하면 표현을 살짝 다듬고 바로 발행할 수 있습니다.”

**실패 시 대체 진행**

- 수정 저장이 지연되면 본문 수정 시연은 짧게만 하고 바로 발행으로 넘어간다.

### 9단계. 발행 결과 확인

**화면명**

- 발행 로딩 화면
- 발행 결과 화면

**라우트 또는 화면 위치**

- `/post-create`
- `PublishResultStep`

**사전 상태**

- 최종 발행 버튼 클릭 완료

**시연자 행동**

- 발행 로딩을 잠깐 보여준다.
- 성공 화면이 뜨면 인스타그램 이동 버튼을 선택한다.

**클릭 위치**

- 성공 시 상단 첫 번째 버튼 `에서 보기`
- 하단 두 번째 버튼 `홈으로 돌아가기`
- 실패 시 첫 번째 버튼 `다시 발행하기`

**화면 반응**

- 성공 시 “발행 성공! 고생하셨습니다.” 문구와 캐릭터, 효과가 나타난다.
- 실패 시 재시도 버튼이 나타난다.

**설명 멘트**

- “생성만 하는 것이 아니라, 실제 인스타그램 게시까지 연결됩니다.”
- “성공하면 바로 게시 결과를 확인할 수 있고, 실패하면 다시 발행하기로 재시도할 수 있습니다.”

**실패 시 대체 진행**

- 발행 실패 시 `다시 발행하기`를 보여주고, 필요하면 준비된 성공 계정이나 사전 캡처 화면으로 우회한다.

### 10단계. 실제 인스타그램 게시 결과 확인

**화면명**

- 외부 인스타그램 게시물 화면

**라우트 또는 화면 위치**

- 발행 성공 후 외부 링크 이동

**사전 상태**

- 발행 성공 완료

**시연자 행동**

- 실제 게시된 인스타그램 게시물을 보여준다.

**클릭 위치**

- 발행 성공 화면의 첫 번째 버튼 `에서 보기`

**화면 반응**

- 새 창 또는 외부 화면으로 실제 게시물이 열린다.

**설명 멘트**

- “방금 앱 안에서 만든 결과가 실제 인스타그램 게시물로 바로 이어진다는 점을 보여주는 장면입니다.”

**실패 시 대체 진행**

- 외부 브라우저 전환이 어려우면 사전에 열린 인스타그램 게시물 탭 또는 캡처 이미지를 보여준다.

### 11단계. 마이페이지 통계 확인

**화면명**

- 마이페이지 통계 화면

**라우트 또는 화면 위치**

- `/mypage`

**사전 상태**

- 홈 또는 발행 결과 화면에서 이동 가능

**시연자 행동**

- 하단 탭에서 `내 정보`로 이동한다.
- 상단 탭에서 `통계`를 확인한다.
- 주간 달성률, 가게 노출수, 방문 관심도를 보여준다.

**클릭 위치**

- 하단 탭 오른쪽 `내 정보`
- 상단 탭 첫 번째 `통계`

**화면 반응**

- 주간 포스팅 현황 또는 이번 주 달성률 카드가 보인다.
- 가게 노출수와 방문 관심도 카드가 표시된다.

**설명 멘트**

- “게시를 한 번 만드는 데서 끝나는 게 아니라, 이후 성과를 계속 확인할 수 있습니다.”
- “점주는 주간 달성률과 가게 노출수, 방문 관심도를 통해 다음 게시 전략을 판단할 수 있습니다.”

**실패 시 대체 진행**

- 통계 수치 반영이 즉시 보이지 않으면, 기존 누적 데이터가 보인다는 점을 설명하며 통계 화면 구조 자체를 중심으로 시연한다.

## 3. 시연 전 체크리스트

- 로그인된 계정인지 확인
- 인스타그램 연동이 완료된 계정인지 확인
- 게시 가능한 인스타그램 비즈니스 또는 운영 계정인지 확인
- 홈 진입 시 상단 문구와 TTS가 정상 노출되는지 확인
- 마이크와 카메라 권한이 허용되어 있는지 확인
- 5초 내외 시연용 촬영 환경이 준비되어 있는지 확인
- 발행 성공 후 확인할 인스타그램 계정 접근이 가능한지 확인
- 마이페이지 통계 데이터가 비어 있지 않은지 확인

## 4. 시연 중 주의사항

- 홈 입력 단계에서는 게시 의도가 분명한 문장을 사용하는 것이 안전하다.
- 음성 입력이 불안정하면 즉시 텍스트 입력으로 전환한다.
- 로딩 단계는 너무 오래 기다리지 말고 “AI가 처리 중”이라는 설명 멘트와 함께 자연스럽게 넘긴다.
- 카메라 촬영은 길게 하지 말고 짧고 안정적으로 진행한다.
- 발행 실패 가능성에 대비해 성공 화면 캡처나 실제 인스타 게시물 예시를 준비해 둔다.
- 이번 문서에는 온보딩 전체 흐름, 배포 설명, 외부 서비스 설명, DB 덤프 설명을 섞지 않는다.
