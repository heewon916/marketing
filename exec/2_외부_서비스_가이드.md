# 프로젝트 외부 서비스 가입 및 활용 가이드

## 문서 개요

이 문서는 프로젝트에서 사용하는 외부 서비스의 가입 및 활용에 필요한 정보를 정리한 문서다.
정리 대상은 실제 계정 생성, 키 발급, 토큰 설정, 서비스 연동이 필요한 항목으로 한정한다.

### 문서 포함 기준

- 프로젝트 기능 구현에 직접 사용되는 외부 서비스
- 계정, 앱 등록, API 키, OAuth 클라이언트, 서비스 토큰, 서비스 계정 파일이 필요한 서비스
- 현재 저장소의 설정 파일과 코드에서 실제 참조되는 서비스

### 문서 제외 기준

- Postgres, Redis, Jenkins, Docker Compose 같은 내부 인프라
- Docker Hub 이미지, 공개 오픈소스 라이브러리
- Google Fonts 같은 단순 공개 리소스
- 실제 운영값이 저장된 `.env`, `gpu-server/.env`, Firebase 서비스 계정 JSON 본문

### 민감정보 비공개 원칙

- 실제 API 키, Secret, Token, 서비스 계정 JSON 본문은 문서에 기재하지 않는다.
- 실제 운영 도메인, Redirect URI, Bucket 이름, 내부 API 엔드포인트는 문서에 기재하지 않는다.
- 문서에는 `필요한 값의 종류`, `형식`, `코드 반영 위치`, `준비 시 주의사항`만 정리한다.

## 2. 서비스별 상세 가이드

### 2-1. Kakao Developers

**무엇인지**

- Kakao 지도 JavaScript SDK를 제공하는 개발자 플랫폼이다.

**프로젝트 사용 목적**

- 프론트엔드에서 지도 표시와 장소 관련 기능에 사용한다.

**가입/발급 위치**

- Kakao Developers 공식 포털에서 애플리케이션을 생성하고 JavaScript 키를 발급한다.

**준비해야 할 값**

- JavaScript 키
- 서비스 도메인 등록값

**프로젝트 반영 위치**

- 환경 변수: `VITE_KAKAO_MAP_KEY`
- 사용 코드: `fe/src/utils/loadKakaoMap.js`
- 빌드 주입: `compose.yaml`, `fe/Dockerfile`

**구현 근거 파일**

- `.env.example`
- `compose.yaml`
- `fe/src/utils/loadKakaoMap.js`

**운영 시 주의사항**

- 등록 도메인이 일치하지 않으면 SDK 로딩이 실패할 수 있다.
- 문서에는 실제 서비스 도메인을 쓰지 않고, 도메인 등록 필요 사실만 적는다.

### 2-2. Firebase / Google

**무엇인지**

- Firebase Web SDK, Firebase Cloud Messaging, Firebase Analytics, 서비스 계정 기반 서버 연동을 포함하는 Google 계열 서비스다.

**프로젝트 사용 목적**

- 프론트엔드 웹 앱 초기화
- 웹 푸시 알림 발급 및 수신
- Analytics 사용
- 백엔드의 Firebase 서버 연동

**가입/발급 위치**

- Firebase 콘솔에서 프로젝트를 생성하고 Web App을 등록한다.
- 필요한 경우 Cloud Messaging과 서비스 계정 키를 함께 발급한다.

**준비해야 할 값**

- Web App 설정값
  - `apiKey`
  - `authDomain`
  - `projectId`
  - `storageBucket`
  - `messagingSenderId`
  - `appId`
  - `measurementId`
- 웹 푸시용 VAPID 키
- 서버 연동용 서비스 계정 JSON 파일
- Firebase 사용 여부 플래그

**프로젝트 반영 위치**

- 프론트 환경 변수
  - `VITE_FIREBASE_API_KEY`
  - `VITE_FIREBASE_AUTH_DOMAIN`
  - `VITE_FIREBASE_PROJECT_ID`
  - `VITE_FIREBASE_STORAGE_BUCKET`
  - `VITE_FIREBASE_MESSAGING_SENDER_ID`
  - `VITE_FIREBASE_MEASUREMENT_ID`
  - `VITE_FIREBASE_APP_ID`
  - `VITE_FIREBASE_VAPID_KEY`
- 백엔드 환경 변수
  - `FIREBASE_ENABLED`
  - `FIREBASE_SERVICE_ACCOUNT_PATH`
- 사용 코드
  - `fe/src/lib/firebase.js`
  - `fe/src/features/notification/lib/getFcmToken.js`
- 배포 연동
  - `common/Jenkinsfile`에서 서비스 계정 JSON을 Secret File로 주입

**구현 근거 파일**

- `.env.example`
- `compose.yaml`
- `common/Jenkinsfile`
- `fe/src/lib/firebase.js`
- `fe/src/features/notification/lib/getFcmToken.js`
- `be/src/main/resources/application.properties`

**운영 시 주의사항**

- 서비스 계정 JSON은 문서에 본문을 절대 넣지 않는다.
- FCM 토큰 발급은 HTTPS 또는 보안 컨텍스트가 필요하다.
- `FIREBASE_ENABLED`는 현재 배포 파이프라인에서 유효성 검증 대상이다.

### 2-3. Meta Developers / Instagram Graph API

**무엇인지**

- Instagram OAuth 로그인과 게시 API 연동을 위한 Meta Developers 플랫폼 및 Instagram Graph API다.

**프로젝트 사용 목적**

- Instagram 계정 연동
- OAuth 기반 사용자 인증/인가
- 이미지 게시 및 게시 상태 조회

**가입/발급 위치**

- Meta Developers에서 앱을 생성하고 Instagram 관련 제품을 연결한다.

**준비해야 할 값**

- OAuth Client ID
- OAuth Client Secret
- Redirect URI
- Instagram 비즈니스/전문 계정 연동 전제
- 필요한 권한 범위

**프로젝트 반영 위치**

- 환경 변수
  - `INSTAGRAM_CLIENT_ID`
  - `INSTAGRAM_CLIENT_SECRET`
  - `OAUTH_REDIRECT_URI`
- Spring OAuth 설정
  - `be/src/main/resources/application.properties`
- 게시 API 사용 코드
  - `be/src/main/java/com/matketing/be/domain/content/client/InstagramPublishClient.java`

**구현 근거 파일**

- `.env.example`
- `compose.yaml`
- `be/src/main/resources/application.properties`
- `be/src/main/java/com/matketing/be/domain/content/client/InstagramPublishClient.java`

**운영 시 주의사항**

- Redirect URI는 Meta 콘솔 등록값과 정확히 일치해야 한다.
- 문서에는 실제 Redirect URI를 쓰지 않고 형식과 필요성만 적는다.
- 게시 기능은 공개 접근 가능한 이미지 URL을 전제로 하므로 CloudFront 공개 URL 체계와 함께 관리해야 한다.

### 2-4. AWS S3 / CloudFront

**무엇인지**

- S3는 객체 저장소, CloudFront는 정적 콘텐츠 배포 CDN이다.

**프로젝트 사용 목적**

- 생성 이미지/영상 업로드
- 업로드된 리소스의 외부 공개 URL 제공
- 프론트엔드와 Instagram 게시용 미디어 URL 조합

**가입/발급 위치**

- AWS 계정에서 S3 버킷과 CloudFront 배포를 생성한다.
- 애플리케이션 전용 IAM 자격 증명을 준비한다.

**준비해야 할 값**

- S3 Bucket 이름
- AWS Region
- S3 Access Key
- S3 Secret Key
- CloudFront 배포 도메인
- 프론트엔드 표시용 CloudFront 도메인

**프로젝트 반영 위치**

- 환경 변수
  - `S3_BUCKET_NAME`
  - `S3_REGION`
  - `S3_ACCESS_KEY`
  - `S3_SECRET_KEY`
  - `CLOUDFRONT_DOMAIN`
  - `VITE_CLOUDFRONT_DOMAIN`
- 서비스 사용 위치
  - Spring `content.s3.*`
  - FastAPI S3 관련 설정
  - 프론트 이미지 URL 조합

**구현 근거 파일**

- `.env.example`
- `compose.yaml`
- `be/src/main/resources/application.properties`
- `ai/app/core/config.py`

**운영 시 주의사항**

- `CLOUDFRONT_DOMAIN`은 현재 Jenkins 검증상 프로토콜 없이 도메인 형식만 허용된다.
- 실제 버킷 이름과 실제 배포 도메인은 문서에 적지 않는다.
- S3 키는 서버 전용 민감정보로 취급한다.

### 2-5. Naver Cloud Clova

**무엇인지**

- Naver Cloud의 음성 AI 계열 API다.

**프로젝트 사용 목적**

- STT: 음성 인식
- TTS: 음성 합성

**가입/발급 위치**

- Naver Cloud Platform에서 Clova Speech 및 TTS 관련 서비스를 활성화하고 인증 정보를 발급한다.

**준비해야 할 값**

- STT Base URL
- STT Secret Key
- STT 언어 및 옵션 값
- TTS Base URL
- TTS Client ID
- TTS Client Secret
- TTS Speaker 및 Timeout 설정값

**프로젝트 반영 위치**

- 환경 변수
  - `CLOVA_STT_BASE_URL`
  - `CLOVA_STT_SECRET_KEY`
  - `CLOVA_STT_LANG`
  - `CLOVA_STT_ASSESSMENT`
  - `CLOVA_STT_UTTERANCE`
  - `CLOVA_STT_BOOSTINGS`
  - `CLOVA_STT_GRAPH`
  - `CLOVA_STT_FFMPEG_PATH`
  - `CLOVA_STT_TIMEOUT_SECONDS`
  - `CLOVA_TTS_BASE_URL`
  - `CLOVA_TTS_CLIENT_ID`
  - `CLOVA_TTS_CLIENT_SECRET`
  - `CLOVA_TTS_SPEAKER`
  - `CLOVA_TTS_TIMEOUT_SECONDS`
- Spring 설정
  - `be/src/main/resources/application.properties`

**구현 근거 파일**

- `.env.example`
- `compose.yaml`
- `be/src/main/resources/application.properties`

**운영 시 주의사항**

- Secret Key와 Client Secret은 문서에 기재하지 않는다.
- STT/TTS는 호출 제한, 사용량, 과금 정책을 분리해 확인해야 한다.
- `ffmpeg` 경로는 외부 서비스 값이 아니라 런타임 설정이므로 서버 준비 항목으로만 본다.

### 2-6. Hugging Face

**무엇인지**

- 모델 저장소 접근과 모델 아티팩트 다운로드에 사용하는 외부 플랫폼이다.

**프로젝트 사용 목적**

- GPU 서버에서 모델 이미지를 실행할 때 필요한 Hugging Face 모델 접근
- Jenkins 또는 GPU 서버에서 모델 다운로드/캐시 사용

**가입/발급 위치**

- Hugging Face 계정을 생성하고 Access Token을 발급한다.

**준비해야 할 값**

- Hugging Face Access Token
- 접근할 모델 저장소 식별자

**프로젝트 반영 위치**

- 환경 변수
  - `HF_TOKEN`
- GPU 서버 사용 위치
  - `gpu-server/docker-compose.yaml`
- Jenkins 사용 위치
  - `common/Jenkinsfile`

**구현 근거 파일**

- `.env.example`
- `gpu-server/.env.example`
- `gpu-server/docker-compose.yaml`
- `common/Jenkinsfile`
- `ai/app/core/config.py`

**운영 시 주의사항**

- 토큰 권한은 최소 권한 원칙으로 발급한다.
- 문서에는 실제 토큰과 모델 접근 권한 범위를 적지 않는다.
- 현재 운영 구조는 별도 GPU 서버 기준이므로 모델 접근 토큰도 그 서버 운영 범위에서 관리해야 한다.

### 2-7. OpenAI 또는 OpenAI-compatible VLM provider

**무엇인지**

- OpenAI API이거나 OpenAI API 형식을 따르는 외부 모델 제공자다.

**프로젝트 사용 목적**

- Spring에서 외부 LLM 호출
- FastAPI에서 최종 이미지 편집 계획용 비전-언어 모델 호출

**가입/발급 위치**

- 사용하는 모델 제공자의 공식 콘솔 또는 API 발급 포털에서 키를 발급한다.
- 이 프로젝트는 실제 OpenAI일 수도 있고 OpenAI-compatible 엔드포인트일 수도 있으므로 제공자별 운영 문서와 함께 관리한다.

**준비해야 할 값**

- API Key
- Base URL
- 모델명
- Endpoint 경로
- Timeout, token, sampling 관련 운영값

**프로젝트 반영 위치**

- Spring 환경 변수
  - `OPEN_AI_API_KEY`
  - `CHAT_MODEL_BASE_URL`
- FastAPI 환경 변수
  - `FINAL_EDIT_MODEL_BASE_URL`
  - `FINAL_EDIT_MODEL_API_KEY`
  - `FINAL_EDIT_MODEL_NAME`
  - `FINAL_EDIT_MODEL_CHAT_ENDPOINT`
  - `FINAL_EDIT_MODEL_HEALTH_ENDPOINT`
  - `FINAL_EDIT_MODEL_MAX_TOKENS`
  - `FINAL_EDIT_MODEL_TEMPERATURE`
  - `FINAL_EDIT_MODEL_TOP_P`
  - `FINAL_EDIT_MODEL_TIMEOUT_SECONDS`
- 관련 코드
  - `ai/app/core/config.py`
  - `ai/app/services/final_edit_planner.py`

**구현 근거 파일**

- `compose.yaml`
- `ai/.env.example`
- `ai/app/core/config.py`
- `ai/app/services/final_edit_planner.py`
- `be/src/main/resources/application.properties`

**운영 시 주의사항**

- Base URL이 외부 SaaS일 수도 있고 사내/별도 서버일 수도 있으므로, 문서에는 실제 주소를 적지 않는다.
- API Key는 저장소에 넣지 않고 배포 환경 변수나 보안 저장소로만 관리한다.
- 모델 제공자가 바뀌어도 OpenAI-compatible 인터페이스를 유지하면 설정만 교체해 대응할 수 있다.

### 2-8. 공공데이터 API

**무엇인지**

- 기상청 및 에어코리아 계열 공공데이터 API다.

**프로젝트 사용 목적**

- 날씨 컨텍스트 생성

- 대기질 및 측정소 정보 조회

**가입/발급 위치**

- 공공데이터포털 등 해당 기관 API 발급 경로에서 서비스 키를 신청한다.

**준비해야 할 값**

- 기상청 서비스 키
- 에어코리아 서비스 키
- 필요 시 대기질/측정소 분리 키
- 기관별 Base URL 확인값

**프로젝트 반영 위치**

- 환경 변수
  - `KMA_SERVICE_KEY`
  - `AIRKOREA_SERVICE_KEY`
  - `AIRKOREA_AIR_SERVICE_KEY`
  - `AIRKOREA_STATION_SERVICE_KEY`
  - `KMA_FORECAST_BASE_URL`
  - `KMA_WARNING_BASE_URL`
  - `AIRKOREA_AIR_BASE_URL`
  - `AIRKOREA_STATION_BASE_URL`
- Spring 설정
  - `be/src/main/resources/application.properties`

**구현 근거 파일**

- `be/src/main/resources/application.properties`

**운영 시 주의사항**

- 서비스 키는 URL 쿼리 파라미터로 전달될 수 있으므로 로그 노출에 주의한다.
- 문서에는 실제 서비스 키와 실제 운영 호출 예시 URL을 적지 않는다.
- 기관별 요청 제한과 응답 형식 변경 가능성을 별도로 관리한다.

## 3. 민감정보 및 운영값 처리 원칙

- 실제 API Key, Secret, Token, 서비스 계정 JSON은 문서에 기재하지 않는다.
- 실제 운영 도메인, Redirect URI, Bucket 이름, 내부 Base URL은 문서에 기재하지 않는다.
- 환경 변수 이름과 값의 종류만 문서화한다.
- 실제 값은 Jenkins 자격 증명, 서버 보안 저장소, 비공개 `.env` 파일에서만 관리한다.
- 문서 예시는 모두 형식 설명 수준으로만 작성한다.
