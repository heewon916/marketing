# 🛠️ [맡케팅] 포스기용 프론트엔드(플러그인) 실행 계획

`docs/prompts/prompt1.md`의 요구사항을 반영하여 토스 포스기 화면 내부에 띄워질 프론트엔드 앱 개발 실행 계획을 정리합니다.

---

## 1. 프로젝트 초기화 및 환경 설정

*   **프레임워크 스캐폴딩:** Vite를 사용하여 React 프로젝트를 빠르게 초기화합니다. (`npm create vite@latest`)
*   **스타일링 라이브러리 설정:** 시니어 타겟의 직관적이고 큼직한 UI 구성을 위해 관리와 구현이 용이한 Tailwind CSS 또는 Styled-components를 세팅합니다.
*   **환경 변수(ENV) 구성:** 백엔드 개발 서버(ngrok)와 연동하기 위해 `.env` 파일에 `VITE_API_BASE_URL`을 설정합니다.

## 2. API 연동 및 상태 관리 (비즈니스 로직)

*   **상태 정의:** 컴포넌트 내에 다음의 상태들을 정의합니다.
    *   `pin`: 발급받은 6자리 인증번호 (초기값 `null`)
    *   `timeLeft`: 남은 시간 (초기값 `180` - 3분)
    *   `status`: 현재 진행 상태 (`LOADING`, `SUCCESS`, `EXPIRED`, `ERROR`)
*   **API 호출 함수 구현:**
    *   `POST /api/v1/auth/pin/generate` 엔드포인트로 인증번호 발급을 요청하는 비동기 함수(`fetchPinNumber`)를 구현합니다.
    *   요청 성공 시 `pin`과 `timeLeft`를 갱신하고 상태를 `SUCCESS`로 변경합니다.
    *   실패 시 상태를 `ERROR`로 변경합니다.
*   **타이머 동작 로직:**
    *   `useEffect`를 활욯하여 1초마다 `timeLeft`가 1씩 감소하도록 설정합니다.
    *   시간이 0이 되면 상태를 `EXPIRED`로 변경하고 타이머를 종료합니다.

## 3. UI/UX 구현 (고대비 및 시니어 친화적 디자인)

5060 시니어 사장님들이 주요 타겟이므로, 복잡도를 낮추고 시인성을 극대화합니다.

*   **컴포넌트 구조:**
    *   **공통 헤더:** "스마트폰에서 연동 번호를 입력해주세요" 문구 (크고 명확한 폰트)
    *   **로딩 화면:** "번호를 불러오는 중..." 표시
    *   **성공 화면:** 화면 중앙에 6자리 PIN 번호를 매우 크게 배치 (고대비 컬러 적용, 예: 파란색 계열) 및 하단에 남은 시간 시각적 표시 (`03:00` 포맷, 붉은색 계열로 경각심)
    *   **만료/에러 화면:** 실패 사유 안내 텍스트와 함께 크고 누르기 쉬운 **[번호 다시 발급받기]** 버튼 배치
*   **대비 및 폰트:** 웹 접근성을 고려하여 배경과 텍스트의 대비를 높이고 가독성 좋은 산세리프 계열 폰트 적용.

## 4. 안정성 확보 및 예외 처리

*   **토스 환경 대응:** 실제 포스기 웹뷰(iframe)에서 구동되므로, 반응형보다는 포스기 화면 규격에 맞춘 꽉 찬 레이아웃(고정 혹은 비율 조정)을 고려하여 스타일을 적용합니다.
*   **에러 핸들링:** 네트워크 오류, 백엔드 서버 다운 등으로 API 호출 실패 시 사장님이 당황하지 않도록 명확한 한글 메시지와 재시도 액션 버튼을 필수로 노출합니다.
*   **메모리 누수 방지:** 컴포넌트 언마운트 시 혹은 재호출 시 기존 타이머(`setInterval`)가 반드시 클리어(Cleanup)되도록 보장합니다.

## 5. 테스트 및 검증 계획

*   **로컬 테스트:** 로컬 브라우저 맥락에서 기능(타이머 정상 동작, 버튼 재발급, 상태값 전환)을 일차적으로 점검합니다.
*   **ngrok 포워딩 테스트:** ngrok을 실행하여 터널링된 URL 환경에서 통신이 딜레이나 Cross-Origin 문제(CORS) 없이 백엔드와 정상 동작함을 확인합니다.
*   **포스기 모의 테스트:** 포스기와 동일한 화면 비율과 해상도를 개발자 도구의 디바이스 모드로 설정하여 UI 비율과 가독성을 최종 체크합니다.
