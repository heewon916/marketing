# 토스 POS 플러그인 (Iframe 패키지 방식) 실행 계획

`docs/prompts/prompt2.md`의 가이드를 바탕으로, 토스 POS 탭 화면에서 동작하는 Iframe 기반 플러그인을 개발하고 배포하기 위한 단계별 실행 계획입니다.

## 1단계: 프로젝트 환경 설정 및 SDK 설치
- **의존성 설치**: 프로젝트 디렉토리에서 `npm install`을 실행하여 기본 패키지를 설치합니다.
- **SDK 설치/업데이트**: POS 연동에 필수적인 SDK를 최신 버전으로 설치합니다. (`npm install @tossplace/pos-plugin-sdk@latest`)

## 2단계: 탭 메타데이터 설정
- **`public/iframe-manifest.json` 수정**:
  - 플러그인이 POS 기기의 탭 메뉴에 표시될 때 사용할 이름(`tab.title`)과 설명(`tab.description`)을 정의합니다.
  - 이 파일은 빌드 시 루트 디렉토리에 포함되어야 하며, 개발자 센터에서 앱을 식별하는 기준이 됩니다.

## 3단계: 메인 애플리케이션(UI 및 로직) 구현
- **`src/App.tsx` (또는 `App.jsx`) 개발**:
  - **UI 렌더링**: iframe 내부에서 보여질 DOM 기반의 사용자 인터페이스를 개발합니다.
  - **SDK 연동**: `@tossplace/pos-plugin-sdk`를 활용하여 토스트 띄우기, 결제, 정보 조회 등의 POS 네이티브 기능을 호출합니다.
  - **상태 관리**: 비동기 API 호출이 잦은 환경이므로 로딩 상태(Loading)와 에러 상태(Error)에 대한 UI/UX 처리를 꼼꼼하게 구현합니다.

## 4단계: 빌드 및 패키징
- **빌드 실행**: `npm run build` 명령어를 사용하여 프로덕션용 번들을 생성합니다. (결과물은 `dist` 폴더에 저장됨)
- **압축(ZIP) 생성**: 
  - `dist` 폴더 내부의 파일들(`index.html`, `iframe-manifest.json`, `assets/` 등)을 전체 선택하여 압축합니다.
  - **주의**: 폴더 자체를 압축하지 않고, 압축 해제 시 최상단(root)에 `iframe-manifest.json`이 위치하도록 구성해야 합니다.

## 5단계: 개발자 센터 업로드 및 검수
- 토스플레이스 개발자 센터에 접속하여 '포스 플러그인' > '탭 화면' 유형으로 애플리케이션을 생성합니다.
- 앞서 생성한 ZIP 파일을 업로드하고, POS 기기 또는 에뮬레이터에서 정상적으로 Iframe이 로드되고 동작하는지 테스트합니다.
