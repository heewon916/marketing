## 1. 개발계정 신청

### 1.1 개발계정 활용신청

공공데이터포털(`data.go.kr`)에서 로그인한 뒤 검색창에 `에어코리아`를 검색합니다.

절차:

1. 공공데이터포털 로그인
2. 검색창에 `에어코리아` 입력
3. 검색 결과에서 `오픈 API` 탭 선택
4. 필요한 API의 `활용신청` 버튼 클릭
5. 활용목적 및 추가 설명자료를 입력/첨부한 후 활용신청

API 목록 클릭 시 API 상세정보 확인이 가능합니다.

### 1.2 개발계정 승인 및 동기화

- 신청 즉시 승인됩니다.
- 다만 실제 데이터 활용을 위해 공공데이터포털 내 시스템 동기화 시간이 필요합니다.
- 동기화에는 약 1~2시간이 소요될 수 있습니다.

### 1.3 일일 트래픽 허용 횟수

상세기능 단위 기준입니다.

| 계정 구분 | 일일 트래픽 허용 횟수 |
|---|---:|
| 개발계정 | 500회/일 |
| 운영계정 | 10,000회/일 |

## 2. 운영계정 신청

### 2.1 운영계정 활용신청 위치

개발계정 신청 후 공공데이터포털(`data.go.kr`)의 `마이페이지`로 이동합니다.

절차:

1. 공공데이터포털 로그인
2. 마이페이지 이동
3. 신청한 API 목록으로 이동
4. 활용신청 현황에서 운영계정 신청할 API 선택
5. 운영계정 신청 버튼 클릭

### 2.2 활용사례정보 등록

운영계정 신청 시 활용사례정보를 등록해야 합니다.

필수 입력 항목:

- 서비스정보
  - 서비스이름
  - 서비스목적
  - 서비스전달체계유형
  - 서비스 대상
  - 개발언어
  - 출처 표기 여부
  - 데이터 오류 가능성 표기 여부
  - 서비스 상세 설명

특히 `서비스 설명` 란은 필수 입력입니다. 입력 누락 시 승인 반려 처리될 수 있습니다.

서비스 상세 설명 예시:

- 환경대학 환경생 명품과 관련한 제품의 오염 미리 알림생활 및 에어코리아에 필요한 다양한 정보를 제공하는 혁신적인 화상형, 스마트 에어코리아 데이터를 제공
- 시간 정보와 날씨 정보를 제공하는 날씨사용 모바일앱으로 GPS 정보를 활용하여 최근 측정소의 미세먼지 및 대기오염물질 정보를 제공하는 서비스

### 2.3 운영계정 승인 소요기간

활용사례정보 등록 후 활용신청을 하면 담당자 심의 후 승인 처리됩니다.

- 예상 소요기간: 1일 ~ 1주일 이내

### 2.4 증빙 이미지 필수 입력

`기능 및 서비스 화면` 항목에 두 가지 증빙 자료를 반드시 입력해야 합니다.

1. 개발 프로그램 대표화면 이미지
2. 출처 및 데이터 오류 가능성이 표기된 운영 프로그램 이미지

입력 누락 시 승인 반려 처리될 수 있습니다.

### 2.5 데이터 오류 가능성 문구 예시

운영 프로그램 화면에 아래와 같은 취지의 문구를 표시해야 합니다.

```text
데이터는 실시간 관측된 자료이며 측정소 현지 사정이나 데이터의 수신상태에 따라 미수신 될 수 있음
```

또는 서비스 문맥에 맞게 다음처럼 표기할 수 있습니다.

```text
데이터는 실시간 관측 자료이며, 측정소 현지 사정 또는 데이터 수신 상태에 따라 누락되거나 실제와 다를 수 있습니다.
출처: 환경부/한국환경공단
```

## 3. 개발 및 운영 시 주의사항

- 개발계정은 상세기능당 500회/일 제한이 있으므로 개발 중 Redis 캐시 또는 로컬 캐시를 적용하는 것이 좋습니다.
- 운영계정 전환 전에는 실제 서비스 트래픽을 고려하여 호출 횟수 산정이 필요합니다.
- 에어코리아 데이터 활용 시 출처 표기와 데이터 오류 가능성 표기가 필요합니다.
- 외부 API 장애, 데이터 미수신, 측정소 점검 상태를 고려해 null fallback 또는 재시도 로직을 구현해야 합니다.
