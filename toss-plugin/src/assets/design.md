# 맡케팅 서비스 연동 화면 UI 수정 프롬프트

## 🎯 목적

현재 단순 재발급 화면을 →
**맡케팅 서비스 연동 온보딩 화면**으로 변경

---

## 🧱 전체 구조

* 중앙 정렬된 카드형 컨테이너
* 배경 이미지 위에 **반투명 카드 UI**
* 5060 사용자 대상 → **단순 / 직관 / 정보 최소화**

---

## 🎨 스타일 가이드

### 컨테이너

* background: `rgba(255,255,255,0.85)`
* backdrop-filter: `blur(12px)`
* border-radius: `24px`
* padding: `40px`

---

### 컬러

* Primary: `#FF7A3D`
* Text Main: `#222`
* Text Sub: `#666`
* Divider: `#EAEAEA`

---

## 🧾 텍스트 구성

### 상단 탭

* 이름: `맡케팅`

---

### 컨테이너 내부

#### 1. 타이틀 (최상단)

```
맡케팅 서비스 연결하기
```

#### 2. 설명 (타이틀 아래)

```
포스를 연결하여 // 사장님의 마케팅 전략을 분석, 제안해드립니다
```
//에서 줄바꿈

---

## 🔄 단계 영역 (핵심 UI)

### 구성

* 가로 3단 구조
* 아이콘 + 텍스트
* 아이콘 사이 점선 연결

---

### 아이콘 (assets 사용)

* lock icon
* keypad icon
* link icon

👉 스타일

* outline
* stroke: 2px
* 색상: `#FF7A3D`
* 원형 배경 ❌ (아이콘만 사용)

---

### 단계 텍스트 (아이콘 아래)

왼쪽:

```
인증 번호 생성
```

가운데:

```
맡케팅 서비스에 번호 입력
```

오른쪽:

```
서비스 연결 완료
```

---

## 🔘 버튼 영역

### 버튼

```
인증 번호 생성 하기
```

* background: `#FF7A3D`
* color: white
* border-radius: 12px
* height: 56px

---

### 버튼 하단 안내 문구

```
생성 후 맡케팅 서비스에 입력해주세요
```

* font-size: 작게
* color: #666

---

## 📐 레이아웃 기준

### 간격

* 타이틀 ↔ 설명: 12px
* 설명 ↔ 단계: 32px
* 단계 ↔ 버튼: 40px
* 버튼 ↔ 하단 텍스트: 12px

---

### 정렬

* 전체 중앙 정렬
* 단계 3개 동일 간격 (flex space-between)


---
